Google Tricks Search Phrases

Type four words into Google and the whole page does a flip. No loading screen, no pop-up, no explanation. It just spins once and settles back down like nothing happened, which is exactly why people still show it off.

Here’s how to trigger it, where it came from, how far you can push it, and how to build the same effect yourself. It’s part of our Google search tricks list.

Quick answer: Search “do a barrel roll” on Google and the results page spins 360 degrees. Google added it on November 3, 2011 as a nod to Star Fox 64, and “z or r twice” does the same. Recent roundups list it as still working. Try it on a desktop, and expect a short spin that settles back to normal.

How to try the Google barrel roll

  1. Open google.com in a desktop browser.
  2. Type do a barrel roll into the search box, with nothing else.
  3. Press Enter and watch the results page rotate once.
  4. For the same spin, you can also search z or r twice.

That’s the whole trick. It’s a short animation, a second or two, and then the page is back to normal and fully usable.

Where the line comes from

The phrase comes from Star Fox 64, released for the Nintendo 64 on June 30, 1997. In the game, the character Peppy Hare, voiced by Rick May, shouts “do a barrel roll!” to help you dodge enemy fire, and on the controller you do it by pressing Z or R twice. That’s why the second search phrase exists.

The line became an internet joke in the early 2000s, and Google added the trick on November 3, 2011. The Christian Science Monitor covered it the next day under a headline warning about vertigo, which turned out to be good advice. Aviation fans also point out that the move in the game is technically an aileron roll, not a barrel roll, a debate players have been having for years.

Can you spin it more than once?

Some guides say you can add a number, such as “do a barrel roll 10 times,” to make the page spin repeatedly. We couldn’t confirm that in this fact-check, so treat it as a rumor and test it yourself.

What we can confirm is the fan-made version on elgooG. It’s an enhanced copy of the trick, and it offers presets from 2 spins all the way up to 1,000,000. It isn’t affiliated with Google, and the million-spin button is exactly as silly as it sounds.

Build your own barrel roll

If you want to understand the trick, you can recreate it on a page you own. This is plain CSS and one line of JavaScript. It won’t work on google.com, but it’s a nice little project for a homepage or a demo.

@keyframes barrel-roll { to { transform: rotate(360deg); } } body.roll { animation: barrel-roll 1s ease-in-out; } /* then, in JavaScript: */ document.body.classList.add('roll'); setTimeout(() => document.body.classList.remove('roll'), 1000);

The CSS animation does the spinning, and the script adds the class, waits a second, and removes it so the page is ready to roll again. Rotating the whole body can cause odd scrolling on long pages, so try it on a short demo first.

If it won’t spin

  • Type the phrase exactly, in regular Google Search.
  • Use a desktop browser. Chrome is a safe choice.
  • Check whether reduced motion is switched on in your system settings, because it can disable animation.
  • Try a private window to rule out extensions.
  • If none of that works, the page may simply be in a Google app or results view that skips the effect.

A motion warning

A spinning page is fun for most people and unpleasant for some. If animation makes you dizzy, skip this one, or turn on reduced motion first. The next trick in our set is gentler. Google askew only tilts the page a few degrees. For something more dramatic, try the floating page in Google zero gravity mode.
